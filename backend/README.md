# Backend

## Responsabilidade

O backend do ByteBistro é responsável por:

- Expor a API do sistema
- Aplicar as regras de negócio
- Realizar a comunicação com o banco de dados

## Tecnologias

- **Node.js** — ambiente de execução
- **TypeScript** — linguagem utilizada no desenvolvimento
- **Apollo Server** — servidor GraphQL
- **GraphQL** — linguagem de consulta e manipulação de dados da API
- **Prisma** — ORM para acesso ao banco de dados

## Arquitetura

O backend segue o modelo de **monólito modular**, descrito em detalhes em [`docs/arquitetura/arquitetura-atual.md`](../docs/arquitetura/arquitetura-atual.md).
