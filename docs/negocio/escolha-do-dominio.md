# Escolha do Domínio

## Domínio escolhido

O ByteBistro foi desenvolvido dentro do domínio de **restaurantes**, especificamente voltado à digitalização do cardápio e à gestão do fluxo de pedidos.

## Justificativa

O domínio de restaurantes foi escolhido pelos seguintes motivos:

- Apresenta um fluxo de dados claro e didático: **Restaurante → Menu → Produtos → Carrinho → Pedido**
- Permite explorar, de forma prática, conceitos de comunicação entre cliente e servidor (HTTP/GraphQL)
- É um domínio compreensível para fins de apresentação acadêmica
- Possibilita discutir conceitos de arquitetura distribuída (segurança, escalabilidade, resiliência) de forma aplicada a um cenário realista

## Relação com a disciplina

O domínio escolhido serve como base prática para a aplicação dos conceitos estudados na disciplina de Sistemas Distribuídos, tanto na arquitetura atualmente implementada quanto nas propostas de evolução arquitetural discutidas em [`docs/arquitetura/arquitetura-futura.md`](../arquitetura/arquitetura-futura.md).
