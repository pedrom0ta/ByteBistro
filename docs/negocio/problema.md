# Problema

## Descrição

Restaurantes frequentemente lidam com processos de atendimento e organização de pedidos que não estão totalmente integrados, o que pode gerar dificuldades como:

- Falta de centralização das informações do cardápio
- Retrabalho na organização dos pedidos
- Dificuldade de manter o cardápio atualizado e acessível
- Ausência de um fluxo único e claro entre menu, produtos, carrinho e pedido

## Contexto

O ByteBistro parte da observação de que um sistema capaz de centralizar o fluxo **Restaurante → Menu → Produtos → Carrinho → Pedido** pode contribuir para organizar esse processo de forma mais estruturada.

## Escopo do problema no projeto

Este documento descreve o problema motivador do projeto no contexto acadêmico da disciplina de Sistemas Distribuídos. Não são apresentados dados de mercado ou pesquisas quantitativas, pois estes não fazem parte do escopo definido até o momento para o projeto.
